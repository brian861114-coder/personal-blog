## 1. 它是什麼

**產品定位：** 開源、AI 驅動的瀏覽器擴充功能，把網頁閱讀變成語言學習流程：整頁／選取翻譯、TTS、可重用的 Custom AI Actions，以及把結果存進 Notebase 做間隔重複複習。

- 英文 README：「An open-source AI-powered language learning extension for browsers. Supports immersive translation, article analysis, multiple AI models, and more.」來源：https://github.com/mengxi-ream/read-frog/blob/main/README.md
- GitHub description：「Read Frog - Language Learning & Translate | 陪读蛙 - 语言学习与翻译」。來源：https://github.com/mengxi-ream/read-frog
- 官方站 slogan：「Learn languages from the content you love」。現已支援：web pages、YouTube、ebooks；Coming soon：PDFs、comics。來源：https://readfrog.app / https://www.readfrog.app/en
- 官方英文文件：「open-source browser extension for reading in another language」。來源：https://www.readfrog.app/en/docs
- 願景（README）：讓各程度學習者有易用、智慧、個人化的語言學習；「最終讓世界不再依賴人類語言教師」。並聲明產品仍在積極開發。來源：https://github.com/mengxi-ream/read-frog/blob/main/README.md
- 目標使用者（從文件與安裝引導）：要讀外語網頁的人、想學語言的人、要翻譯輸入欄的人。安裝引導選項含 Learn a language / Translate webpages / Translate input fields。來源：https://www.readfrog.app/en/guide/step-1
- 官網宣稱「Installed by over 240,000 users」。來源：https://www.readfrog.app/en
- 營運主體：服務條款與退款政策為 **FEELIO TECHNOLOGIES LTD.**；準據法加拿大。來源：https://www.readfrog.app/en/terms-of-service 、 https://www.readfrog.app/en/refund-cancellation-policy
- 倉庫擁有者 GitHub 個人檔：login `mengxi-ream`，顯示名 MengXi，地點 Vancouver，公司欄 University of British Columbia，個人站 https://mengxi.work 。來源：https://api.github.com/users/mengxi-ream

**注意：** 繁中文件 `/zh-TW/docs` 仍是早期「產品介紹／未來計劃」（含尚未完成的電子書、行動端等），與現行英文文件與官網不一致。來源：https://www.readfrog.app/zh-TW/docs vs https://www.readfrog.app/en/docs

## 3. 架構與技術棧

### 公開 GitHub 倉庫實際是什麼

`mengxi-ream/read-frog` **不是**含多個 `packages/` 的完整產品 monorepo，而是單一套件 **`@read-frog/extension`**（WXT 瀏覽器擴充）。`package.json` `"name": "@read-frog/extension"`, `"version": "1.46.6"`, `"private": true`。來源：https://github.com/mengxi-ream/read-frog/blob/main/package.json

`pnpm-workspace.yaml` 只有 pnpm 政策，沒有 workspace 套件清單。來源：https://github.com/mengxi-ream/read-frog/blob/main/pnpm-workspace.yaml

`wxt.config.ts` 註解寫明：開發時可用 `WXT_USE_LOCAL_PACKAGES` 把別名指到**隔壁 checkout** `../read-frog-monorepo` 的 `packages/definitions` 與 `packages/api-contract`（可用 `WXT_MONOREPO_PATH` 覆寫）。該 monorepo **不在**此公開 repo、也搜不到公開 `read-frog-monorepo`。來源：https://github.com/mengxi-ream/read-frog/blob/main/wxt.config.ts

npm 依賴：`@read-frog/api-contract` 0.14.0、`@read-frog/definitions` 0.4.4。來源：package.json

`nx.json` 只為這一個 extension 專案快取 build/test/lint。來源：https://github.com/mengxi-ream/read-frog/blob/main/nx.json

### 三層產品

1. **瀏覽器擴充（此 repo）**  
   WXT 0.21.4、MV3、React 19、`src/entrypoints/`：`background`、`host.content`、`selection.content`、`subtitles.content`、`interceptor.content`（YouTube timedtext）、`input-injector.content`、`options`、`popup`、`sidepanel`、`offscreen`、`guide.content`、`partner-bridge.content`、`translation-hub` 等。  
   Manifest 權限：`storage`, `tabs`, `alarms`, `cookies`, `contextMenus`, `identity`, `scripting`, `webNavigation`；非 Firefox 另加 `offscreen`, `sidePanel`。`host_permissions`: `*://*/*`。Firefox gecko id `{bd311a81-4530-4fcc-9178-74006155461b}`。來源：wxt.config.ts

2. **官方網站** `https://www.readfrog.app`（文件、定價、帳號、Notebase UI、安裝引導）。預設 `WXT_WEBSITE_URL`。來源：https://github.com/mengxi-ream/read-frog/blob/main/src/env/shared.ts

3. **後端 API** `https://api.readfrog.app`：better-auth（`src/utils/auth/auth-client.ts` 以 cookie + background proxy 打 API）、oRPC（`backgroundOrpcClient` → `${WXT_API_URL}${ORPC_PREFIX}`，header `x-orpc-source: extension`）。Hosted AI 狀態走 `hostedAi.status`。來源：env/shared.ts、orpc/background-client.ts、hosted-ai-status.ts。**API／網站伺服器原始碼不在此公開 repo。**

## 4. 翻譯／AI 如何運作（高層）

### 分流（client 擴充內）

`executeTranslate`：

- **非 API 翻譯：** `google-translate`、`microsoft-translate` → 直接打公開翻譯端點  
- **純 API 翻譯：** `deepl`、`deeplx` → 使用者設定的 key／Base URL  
- **LLM：** `aiTranslate`（Vercel AI SDK 路徑）

來源：https://github.com/mengxi-ream/read-frog/blob/main/src/utils/host/translate/execute-translate.ts

### API keys 住哪

- **使用者 BYOK：** 存在擴充本機設定（browser storage）。隱私政策明文：API keys、model、custom base URL 存在裝置上。匯出可選擇是否包含 keys。來源：https://www.readfrog.app/en/privacy-policy ；https://www.readfrog.app/en/docs/configuration ；https://www.readfrog.app/en/docs/api-key
- **開發用 env：** `.env.development` 的 `WXT_OPENAI_API_KEY` 等（貢獻指南）。正式 build 會拒絕把除 PostHog 以外的 `WXT_*API_KEY` 打進 bundle。來源：https://www.readfrog.app/en/docs/code-contribution/contribution-guide ；wxt.config.ts
- **Google Translate：** 原始碼內嵌公開 client key，打 `https://translate-pa.googleapis.com/v1/translateHtml`。來源：https://github.com/mengxi-ream/read-frog/blob/main/src/utils/host/translate/api/google.ts
- **Hosted／內建 AI：** 不靠使用者 LLM key；擴充用登入 cookie 呼叫 `api.readfrog.app` 的 oRPC；額度／可用性由伺服器判定（未登入只有 ephemeral IP trial pool，用量頁不顯示）。來源：hosted-ai-status.ts；built-in-ai-usage/index.tsx；privacy（帳號）
- **Google Drive 同步：** 若開啟，OAuth token 存在本機；同步檔可含**完整設定含 API keys**。來源：privacy-policy
- **PostHog：** 生產環境需 `WXT_POSTHOG_API_KEY`（分析用，允許打進 bundle）。來源：.env.example；wxt.config.ts

### 請求從哪裡發出

- 網頁翻譯佇列、字幕佇列、LLM generate、Edge TTS 多在 **background service worker** 註冊。來源：https://github.com/mengxi-ream/read-frog/blob/main/src/entrypoints/background/index.ts
- 內容腳本避免 CORS：auth fetch 經 `backgroundFetch`。來源：auth-client.ts
- 自訂／區域端點（Ollama、LM Studio、DeepLX）由瀏覽器／擴充直連使用者填的 URL；CORS 與安全性由使用者負責。來源：ollama／lm-studio docs；privacy Security 段
- Hosted AI 生成：伺服器在過額時拒絕；status 快取 30s 於 session storage。來源：hosted-ai-status.ts 註解

### 已登錄的提供者（`PROVIDER_ITEMS`）

翻譯：Microsoft Translate、Google Translate、DeepLX、DeepL。  
LLM／閘道：Jalapeno Cloud、Atlas Cloud、Custom Chat Complete、Custom Responses、OpenRouter、MiniMax、SiliconFlow、OpenAI、Azure、DeepSeek、Gemini、Anthropic、Grok (xAI)、Amazon Bedrock、Groq、DeepInfra、Mistral、Together.ai、Cohere、Fireworks、Cerebras、Replicate、Perplexity、Vercel、Tensdaq、Ollama、Volcengine、Alibaba Cloud、Moonshot AI、Hugging Face。  
來源：https://github.com/mengxi-ream/read-frog/blob/main/src/utils/constants/providers.ts  
文件要求以擴充 UI 為準，不要死背文件上的預設模型。來源：https://www.readfrog.app/en/docs/providers/built-in-providers

DeepL：無 Base URL 欄；key 以 `:fx` 結尾走 `api-free.deepl.com`，否則 `api.deepl.com`。來源：https://www.readfrog.app/en/docs/providers/deepl

## 7. 限制與隱私（僅官方文件／原始碼）

### 產品限制

- 字幕：沒有 YouTube captions 就無法譯；Smart Segmentation 要 LLM、有延遲／費用、可能讓時間軸較不準。來源：video-subtitles
- TTS：Public Beta。來源：tts docs
- Notebase：登入、擴充與網站同帳號；文件仍稱 beta、歡迎回報。來源：notebase-beta
- Custom AI Actions／存結構化結果：模型需可靠 structured output。來源：api-key、custom-actions
- 內建 Free AI：文件寫**不能**當整頁翻譯提供者，僅 Custom AI Actions。來源：api-key
- 定價頁 vs 條款衝突（兩邊都是官方）：  
  - Pricing Free：20 notes、Limited flashcard review；Pro 含「Built-in AI for AI Actions only」、300 分鐘 AI 字幕／月；Ultra 內建 AI 用於所有功能、GPT-5.6 Luna、1000 分鐘字幕。https://www.readfrog.app/en/pricing  
  - ToS：Free 最多 **50** Notebase notes；付費無上限；**閃卡產生與複習不需付費方案**。https://www.readfrog.app/en/terms-of-service  
- 官網：PDF／漫畫「Coming soon」；ebooks 列在 Now。繁中 docs 仍把電子書當未來計劃。來源：官網；zh-TW/docs
- 擴充要廣域 `*://*/*` host 權限（任意 frame 注入）。來源：wxt.config.ts
- README 自稱積極開發、歡迎 issue。

### 隱私（https://www.readfrog.app/en/privacy-policy ，2026-07-05）

- 設計盡量把資料留在瀏覽器；網路功能含：雲端翻譯、TTS、登入、Notebase sync、Google Drive、網站分析、可選產品分析、付費。
- 本機：設定、keys、翻譯／摘要／字幕分段快取、備份、請求統計、可選的隨機 installation id。
- 帳號／Notebase：姓名、email、認證提供者、筆記與複習紀錄等在其伺服器。
- 使用遠端翻譯／AI／TTS 時會送出選取／頁面／字幕／prompt；若開 content-aware，另送標題與擷取正文。第三方（Google Translate、Microsoft Translator、Edge TTS、OpenAI-compatible、自架）各自政策適用。
- 不賣個資、不用內容做廣告。
- 網站 PostHog：路徑、UTM、登入後可關聯 account id／email／display name；不含密碼、卡號、頁面內文、譯文、API keys。
- 可選「Help improve user experience」：Chrome/Edge **預設開**、Firefox 預設關；事件含安裝 id、版本、瀏覽器、功能名、成敗、延遲；不含頁面內文／譯文／完整 URL／keys。
- 解除安裝可能開 Tally 問卷（版本、OS、UI 語言等）。
- 自架 HTTP 端點安全由使用者負責。
- 聯絡：support@readfrog.app（抓取時常變成 `[email protected]`）；GitHub issues。

Firefox manifest 聲明 `data_collection_permissions` required `none`、optional `technicalAndInteraction`。來源：wxt.config.ts
