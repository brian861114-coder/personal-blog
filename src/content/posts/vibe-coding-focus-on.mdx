哈囉大家好，這裡是為哲。

最近幾年 AI 的風潮席捲全世界，身在台灣的大家一定不陌生。但最近這幾個月，AI 在寫程式上的發展真的是突飛猛進，因此誕生出一個很特別的寫程式流派——**Vibe coding**。

## 什麼是 Vibe coding？

Vibe coding 的核心思想就是：

> **用自然語言而非程式語言來建構程式架構。**

換句話說就是——能夠出張嘴，我幹嘛動手打程式碼？

![什麼是 Vibe coding？核心思想說明](/images/posts/vibe-coding-focus-on/02-what-is-vibe-coding.png)

以前機器聽不懂人類的語言，因此人類必須把想法寫成中間型態的程式碼來跟電腦溝通。但現在，依靠各種對話機器人 LLM 的進步，人們突然發現：機器很像突然「聽得懂人話了！」

剛好我最近就在玩這方面的東西，藉機用圖卡來跟大家分享一下。這次圖卡的背景跟插畫幾乎都是 AI 生成的，大概是我畫十輩子都畫不出來的等級——大概就像你把食材備好，AI 就當大廚幫你把菜炒好的感覺。

![Vibe coding 的神奇之處：程式麻瓜也能做出自己的程式](/images/posts/vibe-coding-focus-on/03-magic.png)

## 但 Vibe coding 不是萬能的

當然，Vibe coding 依舊不是萬能的，它依然有許多缺點跟風險。最明顯的問題是：對越不專業的人來說，Vibe coding 越不像在寫程式，而是在抽獎。

> 當你都不知道自己想要什麼時，AI 也不知道該給你什麼。

常見風險大概是這幾種：

1. **黑盒子陷阱**：程式碼能跑，但你不知道為什麼。
2. **維護修羅場**：Bug 出現時，AI 也可能解釋不清楚。
3. **技術債累積**：快速生成的架構往往缺乏長期擴充性。

![但是，Vibe Coding 仍有黑盒子、維護與技術債風險](/images/posts/vibe-coding-focus-on/04-risks.png)

使用期間也確實遇到很多讓人無言的 AI 內容，但確實讓我對程式設計有了更深的了解。

## 既然有缺點，為什麼還要學？

對我來說，有兩個很實際的原因：

1. **客製化需求**：市面上有相似功能的軟體，但功能有缺陷或限制，沒辦法完全符合我的需求。
2. **錢錢，少少，餓肚子**：有符合需求的產品，但往往要收費，甚至搞訂閱制每個月吸血。

![既然有缺點，為什麼還要學習 Vibe coding？](/images/posts/vibe-coding-focus-on/05-why-learn.png)

## 實戰作品：Focus on

說是這麼說，Vibe coding 真的這麼神嗎？眼見為憑——來看看這個純 Vibe coding 生成、不加一滴手打程式碼的 3C detox 軟體：**Focus on**。

它幫我每月節省了 **240 元**的訂閱費。

![Focus on：純 vibe coding 生成的 3C detox 軟體](/images/posts/vibe-coding-focus-on/06-focus-on-intro.png)

你可能會想：手機限制軟體不是 Play 商店一搜一大堆嗎？但這些軟體對我真正需要的「限制期間不能取消」功能，往往放在訂閱項目中。每個月想從我手中搶 240 元？想得美！於是在剁手跟花錢之間，我選擇了 Vibe coding。

### 主要功能

Focus on 的核心是：在倒數計時期間，禁止你使用手機內的特定 App。

主畫面頂端可以進行相關設定，包含：

- 語言選擇
- 預約排程
- 封鎖清單建立等

主畫面中間可以設定倒數計時時間，並且可以開啟：

- **番茄鐘模式**：每限制 25 分鐘，自動解除限制 5 分鐘
- **嚴格模式**：無法提早結束限制

如果你想在倒數期間播放音樂，也可以藉由主畫面下方的選項，匯入音樂庫內的音樂。
